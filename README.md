# 🌐 Portfolio Website

## 📖 Project Overview

The Portfolio Website is a responsive personal website developed as part of the Frontend Development Internship at [CodeAlpha](https://www.codealpha.tech?utm_source=chatgpt.com). This project is designed to showcase personal information, technical skills, projects, resume, and contact details in a professional and visually appealing format. The website includes smooth scrolling, animations, hover effects, and a fully responsive layout that works seamlessly across desktop, tablet, and mobile devices.

## ✨ Key Features

* 📱 Responsive and modern design
* 👤 About Me section
* 💡 Skills and Technologies section
* 💼 Projects showcase
* 📄 Resume download option
* 📬 Contact section or contact form
* 🔄 Smooth scrolling and animations
* 🎨 Hover effects for interactive elements
* 🧭 Clean and user-friendly interface

## 🛠️ Technologies Used

* 🌐 HTML5
* 🎨 CSS3
* ⚡ JavaScript
